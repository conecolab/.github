# Contributing to CoNeCo Lab
## Purpose
This document describes the standards and procedures under the CoNeCo Lab GitHub Organization.  
All members are expected to follow these guidelines to maintain the quality, consistency, and reproducibility of the laboratory's research outputs.  
---
# Who May Contribute
Contributors may include:  
- Prinicipal Investigator
- Faculty Research Associates
- Research Assistants
- Graduate students
- Undergraduate students
- Approved external collaborators
---
# Repository Standards
Every repository should include the following files:
- README.md
- LICENSE
- CITATION.cff
- CHANGELOG.md
- metadata.json

Repositories should also follow the standard folder structure adopted by CoNeCo Lab.  
---
# Documentation Standards
Every dataset must include sufficient documentation for another researcher to understand:
- what the dataset contains
- how was it collected
- any preprocessing performed
- known limitations
- how it should be cited

---
# Data Quality
Before publishing, contributors should verify that:
- data is complete
- filenames are consistent
- duplicate files have been removed
- documentation matches the dataset
- confidential information has been removed

---
# Ethical considerations
Datasets must not contain:
- Personally Identifiable Information (PII)
- confidential university information
- copyrighted materials without permission
- sensitive information prohibited by ethics approval

Contributors are responsible for ensuring compliance with applicable ethics approvals and institutional policies.  
---
# Version Control
Do not overwrite published datasets.  
Instead:
- update the CHANGELOG.md
- create a new GitHub Release
- increment the repository version

# Repository Naming
Repositories must follow the CoNeCo Lab naming convention.  
Examples:
- 4g-fsl-sdr
- wifi-csi-exercises
- 5g-cde-sdr
- 4g-5g-spectrum-survey-manila
Avoid:
- FinalDataset
- ThesisProject
- Data2027

# Review Process
Before a repository becomes public:
1. Student completes repository.
2. Adviser reviews technical content.
3. Research Assistant reviews documentation.
4. PI approves publication.
5. Repository is published.
---
# Questions
If you are unsure about repository standards, consult your adviser or the Principal Investigator before publishing.
