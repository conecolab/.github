# Repository Publication Checklist
## Purpose
Complete this checklist before requesting repository approval.  
The objective is to ensure every CoNeCo Lab repository meets laboratory pulication standards.  
This checklist should be completed by the student researchers and reviewed by the Research Assistant or Principal Investigator.  
---

- [ ] Repository name follows CoNeCo Lab naming conventions.
- [ ] README completed.
- [ ] Dataset anonymized.
- [ ] Metadata completed.
- [ ] No confidential information.
- [ ] Citation prepared.
- [ ] PI approval
- [ ] Repository published.
- [ ] Release tagged.
