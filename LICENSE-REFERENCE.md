# License Reference
## Purpose
This document provides guidance on selecting an appropriate license for repositories under the CoNeCo Lab GitHub Organization.  
The selected license should reflect the intended use of the repository contents and comply with university policies.  
---
# Datasets
Recommended:
- CC BY 4.0
Allows reuse provided attribution is given.
Suitable for most published research datasets.
---
# Documentation
Recommended:
- CC BY 4.0
---
# Software
Recommended:  
- MIT License
Simple and permissive.
Suitable for most research software.
Alternative:
- Apache 2.0
Recommended when explicit patent protection is desired.
---
# When Not to Publish
Do not publish:
- confidential datasets
- proprietary industry datasets
- datasets containing personal information
- datasets restricted by research agreements
Consult the PI before publishing these materials.
---
# Questions
If uncertain, consult the Principal Investigator before selecting a license.
